# Change lanes

This directory is an append-only handoff for the next human or agent. Read the
lane for the surface you will change, then add a dated entry describing the
user outcome, governing source, files, verification, and remaining caveats.

Lanes:

- `docs/setup-guide.md`
- `templates/configuration.md`
- `templates/skills.md`
- `templates/coordination.md`
- `scripts/validator.md`
- `scripts/harness.md`
